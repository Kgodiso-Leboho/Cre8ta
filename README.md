## About The Project

Cre8ta is a South African creator-brand collaboration platform that connects content creators with brands for paid partnerships. Whether you're a creator looking to monetize your content or a brand searching for authentic voices, Cre8ta provides the tools to discover, connect, and collaborate.

### Key Features

| Feature | Description |
|---------|-------------|
| **Creator Dashboard** | Track earnings, views, campaigns, and engagement metrics |
| **Campaign Marketplace** | Browse and apply to brand campaigns |
| **AI Content Tools** | Generate viral post ideas and captions |
| **Analytics** | Deep insights into your content performance |
| **Payment Management** | Track earnings and payment history |
| **Mobile Responsive** | Fully functional on all devices |
| **Portfolio Builder** | Showcase your best work to brands |
| **Real-time Notifications** | Stay updated on applications and messages |

### Built With
